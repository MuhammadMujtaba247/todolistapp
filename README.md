# ✅ Todo List App

A clean, functional todo list application with full CRUD operations and persistent storage. Built with vanilla HTML, CSS, and JavaScript.

**[Live Demo](https://todolistapp-mujtaba.vercel.app/)** 

## 🎯 Features

- **Add tasks** — Type a task and click "Add Task"
- **Delete tasks** — Remove individual tasks with the delete button
- **Edit tasks** — Click the edit icon, modify text, and submit
- **Mark complete** — Tasks move to bottom with strikethrough styling
- **Undo completion** — Restore a completed task to active status
- **Clear all** — Remove all tasks at once
- **Persistent storage** — Tasks saved to localStorage, survive page refresh
- **Empty state** — Friendly message when no tasks exist

## 🛠️ Technologies

- HTML5
- CSS3 (custom properties, flexbox)
- JavaScript (ES6)
- LocalStorage API
